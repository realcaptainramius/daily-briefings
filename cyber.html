Nov 25–26Treasury’s FinCEN takes some systems offline after unauthorized access and extends filing deadlines to Dec 30

The Financial Crimes Enforcement Network said in a notice on its BSA E-Filing site that it is investigating unauthorized access to a “limited subset” of its systems and has taken some systems offline as a precaution. FIFA said on Nov 26 that it was the victim of a criminal cyberattack that gave unauthorized access to a limited set of personal and business information, and that it is working with law enforcement. Nov 19–251Password says attacker used a hijacked employee GitHub account to plant code that copied customer account data

1Password disclosed that an attacker used a compromised employee GitHub account to browse source code and push malicious code to backend services, which then downloaded customer account data; its investigation began on Nov 19. Reported exposed data includes names, email addresses, account identifiers, public keys, activity timestamps and tokens from some emailed invitation and account-recovery links; SecurityWeek also reports that Secure Remote Password verifiers were taken, a detail not confirmed in other summaries seen. The company says vaults, stored items and the keys protecting them, account recovery keys and its apps and extensions were not affected, and it has seen no account takeovers using the exposed tokens. It disabled the account, invalidated a stolen token, rotated infrastructure credentials and restored clean services, but has not said how the GitHub account was compromised or how many customers are affected; it warns users to expect phishing. Seen via search summaries only; 1Password’s own notice was not opened.

Nov 16–24Optimizely supply-chain attack serves skimmer and wallet-swapping code on about 178 organizations’ websites

Attackers planted malicious JavaScript in the customer-editable Project JavaScript of Optimizely Web projects, and Optimizely’s CDN served it to visitors of sites run by about 178 organizations, including CNN, the BBC, Fox News, Zoom and Salesforce. Report URI’s Scott Helme found the code in 188 of 1,611 snippets checked, says it was not CDN cache poisoning, and reports every file clean by 23:11 UTC on Nov 16. Reported payloads swapped cryptocurrency wallet addresses, skimmed payment cards, collected cookies and screenshots and pushed some iPhone visitors toward exploit code. Optimizely confirmed the attack on Nov 17 and blamed a flaw in its Experimentation account signup flow, but has not explained how that gave write access to unrelated customer projects or how many projects were changed. Losses are unclear: earlier reports put attacker wallet receipts at about $6,600–7,000, while blockchain firm Bitquery counts 19 payments worth about $2,260. The affected sites’ own servers were reportedly not breached. On Nov 18 Optimizely said remediation was complete and published an initial findings report saying the attacker abused the signup flaw on Nov 16 to impersonate users on targeted customer accounts and insert JavaScript into their projects; it says this was “not a credentials breach.” In a Nov 19 update it said fewer than 5% of its customers were affected and no services still contain malicious JavaScript. Coverage names the iOS payloads as the Coruna and DarkSword exploit kits, though Hudson Rock says the evidence does not show successful device exploitation. Seen via search summaries only. CISA added the signup-flow flaw to KEV on Nov 24.

Nov 18–24Unpatched flaw in abandoned Idunno.AntiCsrf ASP.NET library exploited to take over IIS servers

Mandiant disclosed CVE-2026-131914 (CVSS 4.0 score 9.3), an insecure deserialization flaw in Idunno.AntiCsrf 0.9.1, a third-party anti-CSRF module for ASP.NET WebForms; a single unauthenticated HTTP POST can run code in the IIS worker process, and Mandiant says it is exploited in the wild. The project was last updated in December 2008 and will not be patched, so the advice is to remove the module and its Web.config entries, delete the DLL, review IIS logs for unusual .aspx POSTs and rotate configuration secrets. Because the DLL was never published on NuGet, package audits may miss it. Sources give Nov 18 or 19 for the disclosure, with wide coverage around Nov 22–23. Seen via search summaries only; Mandiant’s advisory was not opened. watchTowr also reports in-the-wild exploitation, and CISA added the flaw to KEV on Nov 24.
