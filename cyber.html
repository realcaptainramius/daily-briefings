Vulnerabilities & Exploits

Oct 15CISA reportedly adds critical Atlassian Data Center flaw CVE-2026-21589 to KEV after exploitation within hours of public PoC

CVE-2026-21589 (CVSS 9.3) is a path-traversal/arbitrary file access flaw affecting eight Atlassian Data Center products, including Confluence, Jira, Bitbucket and Bamboo. watchTowr published technical details Oct 6 and exploitation attempts followed quickly; VulnCheck tracked exploitation from Oct 7. Security Affairs and Senserva report the CISA KEV addition on Oct 15 with a federal deadline of Oct 18, but CISA’s own alert was not reviewed and early reports said it was not yet listed. Atlassian published fixed versions; where patching is delayed, cut instances off from the internet.

Oct 14CISA adds four exploited flaws to KEV: PAN-OS, Cisco Secure Email Gateway and both AhsayCBS bugs

CISA’s Oct 14 alert lists CVE-2026-0322 (Palo Alto Networks PAN-OS code injection), CVE-2026-76519 (Cisco Secure Email Gateway path traversal), and two AhsayCBS flaws, CVE-2026-105133 and CVE-2026-105134 (Huntress reported exploitation of the pair, with web shells and cryptominers dropped, from Oct 7; patch status for the latest 10.3.4 release was disputed). Federal civilian agencies have until Oct 17 to remediate. Palo Alto reportedly confirmed “very limited exploitation” of the PAN-OS flaw. Help Net Security reported the additions on Oct 15. The PAN-OS and Cisco entries come from the CISA alert title and search summaries; vendor advisories, CVSS scores and exploitation details for those two were not reviewed.

Oct 13Ivanti Connect Secure authentication-bypass zero-day CVE-2026-104935 exploited; CISA adds to KEV

Ivanti disclosed CVE-2026-104935 (CVSS 8.6) on Oct 13 and confirmed exploitation of a limited number of customers before disclosure. Volexity, which found the activity, tracks the actor as UTA0576 and says it chained the flaw since at least Oct 3 with other bugs to get root-level code execution on fully patched appliances, leaving no malware or web shell and tampering with logs. Fixes cited: 22.8R2.5 and 25.1.1.2, plus 25.1.3.0/25.1.3.1; sources differ on the affected-version list and on whether a privilege-escalation fix is still pending. Volexity assessed with low confidence that the motive is criminal rather than espionage. CISA added it to KEV Oct 13 and urged immediate updates. Because logs may be altered, check appliance integrity as well as logs.

Oct 13Microsoft’s record October Patch Tuesday fixes 1,400+ CVEs; Windows Shell zero-day CVE-2026-96951 exploited

BleepingComputer’s headline counts 1,411 flaws and three zero-days; other outlets count 1,407 to 1,413, and some report only one actively exploited. The exploited one, CVE-2026-96951 (CVSS 8.8), is a Windows Shell command-injection flaw that bypasses a security feature (Mark of the Web per BleepingComputer). CISA added it to KEV Oct 13 with a federal deadline of Oct 16 (now passed); Microsoft has not said who is exploiting it. Two other zero-days were publicly disclosed, in .NET Framework-related components. Dark Reading also reports Outlook.com was affected but already patched, from a single source. One outlet lists CVE-2026-92707 as exploited, which other reports do not support.

Threat Actor & APT Activity

Oct 15Google/Mandiant: China-nexus ARMORY CASTLE exploited BeyondTrust Remote Support zero-day CVE-2026-102764 since Aug 29

Google Threat Intelligence Group and Mandiant attribute exploitation to ARMORY CASTLE (formerly UNC5221, also linked to WARP PANDA). The flaw (CVSS 4.0 9.3) is an improper origin validation bug in an internal messaging component that lets an unauthenticated attacker perform file operations. Mandiant found the SAWFLY web shell, credential harvesting and downstream access. BeyondTrust found the hosted activity Sept 28, shipped patch BT26-05 on Oct 8 and disclosed the CVE Oct 15. All Remote Support versions through 26.2.3 are affected; self-hosted customers should confirm the patch is applied. Details come from search summaries; sources differ slightly on SaaS patch timing.
