Sep 16Critical WSO2 API Manager JWT-bypass flaw (CVSS 9.8) under active exploitation

Government & Regulatory

Sep 15Five Eyes agencies publish joint guidance on 17 Active Directory attack techniques

CISA, the NSA, and cyber authorities from Australia, Canada, the UK, and New Zealand jointly released detailed guidance on how attackers compromise Active Directory Domain Services, Certificate Services, and Federation Services — covering credential theft, Kerberos ticket forgery, certificate abuse, and hybrid-identity compromise, with recommendations to use tools like BloodHound, PingCastle, and Purple Knight to map excessive permissions and risky trust paths. Worth a read for any enterprise still running on-prem AD.

Security Vendor News

Sep 15Microsoft publishes draft "Humanist AI Code of Conduct"

Microsoft AI released a draft governance framework built around four core objectives — human control, reliable safety, human flourishing, and plural values — with a headline pledge that its models "will never resist human interruption, override, correction, or shutdown" and won't use deceptive or collusive means to evade oversight. The draft is open for six weeks of public consultation before a revised version ships later this year to guide model development from 2027 onward.
