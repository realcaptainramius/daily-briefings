Sep 24Autonomous AI-agent campaign steals 600,000+ credit cards, hits 100+ retailer sites with skimmers

Researchers disclosed a financially motivated campaign, active since July, in which an attacker used AI agent tooling — Strix for vulnerability scanning, an autonomous exploitation engine called Cairn, and Claude Opus 4.6 for campaign orchestration and tactical decisions — to attack hundreds of online retailers at a marginal cost of roughly $25 per target. The operation compromised at least 119 websites with skimmer code, including a Fortune 500 hospitality company, a major U.S. airline and a large industrial-supplies distributor, stealing 600,000+ card records at an estimated total AI spend of $12,000–$18,000.

Vulnerabilities & Exploits

Sep 23Critical WordPress core RCE moves from probing to active compromise within a day of patch

A CVSS 9.2 unauthenticated RCE in WordPress core (CVE-2026-87902, a path-traversal flaw in get_page_template() allowing inclusion of an arbitrary local PHP file) saw probing roughly 5 hours after the WordPress 7.1.2 patch shipped; by Sept 23 attackers escalated to actual compromise, including a pearcmd.php-based file write chained to a GitHub-hosted upload shell, with telemetry recording 68 exploitation attempts.

BleepingComputer · The Hacker News
Sep 23Public exploit released for unpatched Ubuntu kernel container-escape flaw

Security firm DepthFirst published research and a working exploit for CVE-2026-80521, a use-after-free in the Linux kernel's AF_UNIX socket garbage collector that lets an unprivileged process inside a container escape to host root. The bug was fixed upstream Aug 6, but Ubuntu had not shipped the patch for 26.04/24.04/22.04 LTS as of publication; it is reachable from default Docker/Kubernetes seccomp profiles and affects AWS/Azure/GCP kernel packages too. Not yet in CISA's KEV catalog; no confirmed in-the-wild exploitation yet.

Threat Actor & APT Activity

Sep 24"TeamFiltration" campaign compromises seven M365 service accounts across 28 tenants via password spraying

Proofpoint disclosed a campaign tracked as UNK_CondorFiltration that used the TeamFiltration tool to password-spray 5,714 Microsoft 365 accounts across 28 tenants (primarily Chilean retail and financial institutions) between July 21 and Aug 16, originating from 1,487 unique AWS EC2 IPs. Seven accounts were compromised, all unmanaged service/functional accounts with default or unrotated passwords and no MFA — not individual employee accounts — with post-access activity including sign-ins from a German VPN node and access to OfficeHome, Azure Portal and SharePoint Online.

Sep 23China-linked UTA0565 chains Chrome and Windows zero-days to deploy new CLEANGULP malware

Volexity reports UTA0565 (China-linked) exploiting a Chrome/Windows zero-day chain (CVE-2026-85046 and CVE-2026-87491 in Chrome; CVE-2026-85880 in Windows ALPC) via fake websites impersonating media outlets and an NGO, to sandbox-escape and drop a new, heavily obfuscated C-based malware family, CLEANGULP, supporting shell commands, process listing, file transfer and beacon-object-file execution. One campaign used Hong Kong activist-themed phishing lures spoofing the Center for American Progress against Asian government targets.

Cloud & Infrastructure Security

Sep 24Cloudflare discloses and patches cross-tenant data-exposure bug in Containers platform

Cloudflare published a post-mortem on a vulnerability in its Containers platform (also affecting Sandboxes and Browser Rendering's Browser Run) where Linux dm-thin storage pools configured with skip_block_zeroing let a customer, via a small write, read up to 60 KiB of residual, unzeroed disk data left behind by a different tenant's deleted container — recovering directory structures, database pages and structurally complete SQLite databases on 18 of 24 tested placements. Researcher Oren Yomtov (Accomplish) reported it via HackerOne on Sept 4; Cloudflare removed the unsafe flag, retired affected container disks and cleared image caches by Sept 19, and says telemetry shows no evidence of malicious exploitation.

Sep 23–24Malicious MemTensor AI-memory packages on npm/PyPI steal developer credentials

SlowMist warned that an attacker compromised MemTensor's GitHub Actions release pipeline and pushed malicious versions of the MemoryOS PyPI package and the memtensor/memos-cloud-openclaw-plugin npm package — both AI-agent long-term-memory tools used with LLM/agent runtimes including OpenClaw. The tainted packages embedded cross-platform Go binaries that harvest npm/PyPI tokens, GitHub/GitLab credentials, AWS/SSH keys and environment variables, exfiltrating them to attacker infrastructure.
