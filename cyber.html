Breaches & Incidents

Sep 18–19CrowdSec revises breach account: investor and user data did leak, contradicting its first statement

French security vendor CrowdSec disclosed that an attacker copied ~170 private GitHub repos on May 22 using a former employee's still-active account, itself compromised via May's TanStack npm supply-chain attack (CVE-2026-45321) — the same campaign that hit Mistral AI and OpenAI. The leaked archive, posted publicly Sept 16, contained 83 users' emails and 51 investors' names/emails/investment details from 2020. Notably, CrowdSec's Sept 17 first statement said "no client data, name, or organization was leaked" and blamed a backdoored component directly; the Sept 18 follow-up reversed both claims. CrowdSec says its public IP-blocklist engine and infrastructure were not touched.

Vulnerabilities & Exploits

Sep 19CISA adds three actively-exploited Linux kernel flaws to KEV; patch deadline is today (Sep 21)

CVE-2025-39682 (CVSS 9.8, TLS receive-path memory disclosure/DoS), CVE-2026-53266 (CVSS 8.8, ebtables SNAT/ARP out-of-bounds write enabling local privilege escalation), and CVE-2025-39964 (CVSS 7.8, AF_ALG socket race condition) all carry evidence of active exploitation and a federal remediation deadline of Sept 21 under Binding Operational Directive 26-04 — CISA is also requiring forensic triage, not just patching, for potentially exposed assets.

Sep 19Critical Orkes Conductor pre-auth RCE (CVSS 9.8) exploited in the wild

CVE-2026-58138 lets unauthenticated attackers execute arbitrary OS commands on Orkes Conductor's workflow engine by submitting malicious JavaScript/Python inline workflow definitions, abusing unsandboxed GraalVM evaluators. Fortinet issued an outbreak alert after observing active exploitation.

disclosed ~Sep 18–19Check Point patches critical unauthenticated root RCE in Management/Log Servers

CVE-2026-91843 (CVSS 9.8) is a stack overflow in Check Point's pre-authentication login handler that could let a remote attacker run code as root with no credentials. Check Point shipped a fix via LivePatch and says it has no evidence of in-the-wild exploitation yet — patch before that changes.

Sep 18Working exploit code published for four Linux kernel local-root flaws

Researcher Asim Manizada released technical writeups and working exploits for four kernel bugs — dubbed DirtyAH6, TUNderflow, PPPoEject, and DiagSpill — after a coordinated disclosure hold. All four are already patched in current kernels; no in-the-wild exploitation reported yet, but any system on an older kernel is now a easier target with public exploit code circulating.
