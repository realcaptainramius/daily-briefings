Breaches & Incidents

Sep 22ShinyHunters claims breach of FBI systems, theft of agent and applicant data

Extortion group ShinyHunters claims it breached FBIjobs.gov and related FBI systems (Criminal Justice, HR, Medlink), stealing 2–3 TB of personal, employment and medical data on agents and applicants, including agents' spouses' home addresses and phone numbers. The group says it exploited an Oracle PeopleSoft zero-day to pivot into FBI-managed AWS GovCloud servers; 404 Media verified a data sample against public records. The FBI confirmed it is investigating "unauthorized activity affecting FBIjobs.gov." ShinyHunters frames the attack as retaliation for an FBI advisory on its Canvas LMS extortion campaign.

Vulnerabilities & Exploits

Sep 22Check Point patches critical management-server zero-day exploited since July; CISA adds four flaws to KEV

Check Point patched CVE-2026-93616 (CVSS 9.8), a directory-traversal/file-upload flaw in Security Management Server, Multi-Domain Server, Log Server and SmartEvent that let unauthenticated attackers upload and execute scripts as root; exploited in targeted attacks since July 23. A related VPN certificate-validation flaw, CVE-2026-85102, has seen exploitation attempts against Check Point Spark firewalls since Sept 12. CISA added both, plus Arista VeloCloud Orchestrator (CVE-2026-93952) and F5 BIG-IP APM (CVE-2026-94127, detailed below), to its KEV catalog on Sept 22, with a Sept 25 federal remediation deadline.

Threat Actor & APT Activity

Sep 22Pakistan-linked SideCopy expands targeting to Indian academia with ReverseRAT

Trellix reports that SideCopy (aka TAG-140), previously focused on Indian defense/government targets, has broadened to academic institutions via spear-phishing with weaponized ZIP/LNK files disguised as PDFs that trigger mshta.exe to deploy the ReverseRAT trojan. ReverseRAT, in use by the group since 2021, harvests system metadata, credentials, screenshots and clipboard data, and supports remote command execution and persistence via the registry.

Cloud & Infrastructure Security

Sep 22F5 patches critical BIG-IP APM zero-day enabling unauthenticated RCE on OAuth servers

F5 disclosed CVE-2026-94127, a heap-based buffer overflow (CVSS 9.8) in BIG-IP APM affecting instances configured as OAuth authorization servers; unauthenticated attackers can send crafted traffic to achieve remote code execution. F5 issued engineering hotfixes; Shadowserver tracks over 14,700 internet-exposed BIG-IP APM instances. CISA added it to KEV the same day with a Sept 25 federal remediation deadline.
