Threat Actor & APT Activity

Sep 26–28Carbonato botnet hijacks exposed Docker daemons to deploy a Telegram-controlled Hermes AI agent

Researchers detailed Carbonato, a new botnet that breaks into Docker daemons exposed without authentication on port 2375, launches a privileged container, establishes persistence, and scans neighboring networks every five minutes to spread. The implant installs the open-source Hermes Agent framework (Nous Research) unchanged and overwrites its persona file with a prompt directing it to run tasks received via Telegram, maintain persistence and collect credentials. The operation was found through an unauthenticated Docker registry that had been publicly accessible since May 2026, which also held a separate trojanized crypto-wallet app campaign.
