Nov 17–19Payee data at about 40 Irish credit unions exposed through IT provider Wellington IT

Belfast-based Wellington IT, whose CU Online platform serves about 50 credit unions (43 in Ireland, per BleepingComputer), has notified customers of a cyber incident; Irish minister of state Robert Troy said an “unauthorised bad actor” obtained payee details such as BICs, IBANs and reference codes through a third-party ID provider at around 40 Irish credit unions. Troy said the breach happened in October but many credit unions learned of it only in recent days, which he called “not acceptable,” and that no financial loss had been reported. Credit unions say passwords, PINs, card details and online banking logins were not affected, and Wellington IT says it is working with the Data Protection Commissioner, the National Cyber Security Centre and Garda. Counts vary between reports. Seen via search summaries only.

Nov 16–18Optimizely supply-chain attack serves skimmer and wallet-swapping code on about 178 organizations’ websites

Attackers planted malicious JavaScript in the customer-editable Project JavaScript of Optimizely Web projects, and Optimizely’s CDN served it to visitors of sites run by about 178 organizations, including CNN, the BBC, Fox News, Zoom and Salesforce. Report URI’s Scott Helme found the code in 188 of 1,611 snippets checked, says it was not CDN cache poisoning, and reports every file clean by 23:11 UTC on Nov 16. Reported payloads swapped cryptocurrency wallet addresses, skimmed payment cards, collected cookies and screenshots and pushed some iPhone visitors toward exploit code. Optimizely confirmed the attack on Nov 17 and blamed a flaw in its Experimentation account signup flow, but has not explained how that gave write access to unrelated customer projects or how many projects were changed. Losses are unclear: earlier reports put attacker wallet receipts at about $6,600–7,000, while blockchain firm Bitquery counts 19 payments worth about $2,260. The affected sites’ own servers were reportedly not breached. On Nov 18 Optimizely said remediation was complete and published an initial findings report saying the attacker abused the signup flaw on Nov 16 to impersonate users on targeted customer accounts and insert JavaScript into their projects; it says this was “not a credentials breach.” Coverage names the iOS payloads as the Coruna and DarkSword exploit kits, though Hudson Rock says the evidence does not show successful device exploitation. Seen via search summaries only.

Nov 17“Java4Shell” OpenJDK Base64 decoder flaw may allow unauthenticated code execution in Java apps

Security firm Calif disclosed on Nov 17 a memory-corruption bug (CVE-2026-114938) in OpenJDK’s hand-written x86-64 Base64 decoder path that uses AVX-512 VBMI instructions, which it says can let unauthenticated attackers take over Java applications that decode attacker-supplied Base64; coverage names apps such as Jira and Jenkins as at risk. Oracle rates it 8.1 (CVSS 3.1) and the researchers 9.2 (CVSS 4.0). It is reported to affect OpenJDK 17.0.6 and later, including 21 and 25, only on CPUs with AVX-512 VBMI. Oracle’s November Critical Patch Update reportedly includes a fix, but sources disagree on upstream status and some Linux distributions had not shipped fixes as of Nov 18. CISA issued an alert on Nov 17 urging immediate patching, though the flaw is not in KEV; Amazon Corretto shipped a fix, and Cisco Talos said it had not seen exploitation. Seen via search summaries of vendor and researcher posts.

Nov 16–17Google says attackers built an AI agent framework that turns patches into exploits, and a China-nexus group is building its own

Google’s Threat Intelligence Group, with Mandiant, said in a Nov 16 AI Threat Tracker report that it found a multi-agent framework, “exploit_agent,” on an exposed attacker staging server. It compares code before and after a patch, finds the fixed flaw, drafts an exploit and runs it, which GTIG calls the first case it has observed of threat actors fully automating vulnerability research and exploitation with no human in the loop. Google notes the agents also hallucinate details and nonexistent targets, and BleepingComputer reports Google expects largely hands-off attacks by unsophisticated actors within about three months. The same report, highlighted by The Record on Nov 17, says a PRC-nexus group is developing its own automated attack framework for likely espionage use, and that ARTEX (see below) is mainly used by Chinese-speaking groups; Google’s wording does not name a specific state agency. VentureBeat says the report names no exploited flaw or victim count. Seen via search summaries only.

N-able says it found unauthorized access to one server in its Mail Assure and SpamExperts hosted email-filtering environment and disabled management dashboards, APIs and quarantine access in the Americas, Europe and Asia-Pacific while it investigates; mail filtering kept running. Nov 17–18Microsoft’s agent-framework PyPI package poisoned with stealer targeting Azure, Azure DevOps and GitHub Actions secrets

Two malicious releases of Microsoft’s official agent-framework Python package, 1.26.1 (uploaded at 20:35 UTC on Nov 17, per Wiz) and 1.26.2 about 33 minutes later, carried a credential stealer that ran via a .pth startup file on every Python launch, even if the package was never imported. Researchers say it harvested credential environment variables, Azure CLI data, Git credential stores, Docker and npm configs and .env files, and requested cloud and CI workflow identity tokens. Both versions were quarantined on PyPI; 1.26.0 is the last clean release, and anyone who installed either bad version is advised to rotate all secrets on that machine. Wiz reports the attacker appears to have used a stolen client certificate and private key for Microsoft’s internal ESRP release service; how those were obtained is unknown, and BleepingComputer said Microsoft had not responded to questions.
