Breaches & Incidents

Oct 19OVHcloud CLI releases briefly tampered with secret-stealing binary (single source)

The Stack reports OVHcloud’s CEO said a repository for its command-line tool was briefly compromised after a customer reported it on Oct 19; an attacker reportedly used a developer’s GitHub account to add a binary that retrieves secrets from disk, caught in about 94 minutes. Versions v0.11.0 through v0.15.0 are reported as affected; the CEO advised changing all secrets on affected disks. No independent malware analysis or OVHcloud advisory was seen, so the version list is unconfirmed.

Vulnerabilities & Exploits

Oct 20CISA adds six exploited flaws to KEV, including four in Plex Media Server

CISA’s Oct 20 alert, seen via a search summary of its title and a forum report, adds six entries: four Plex Media Server flaws, CVE-2026-106931 in EG Secure Solutions SiteGuard Server Edition and CVE-2026-110936 in Siemens Software Center. Oct 15CISA reportedly adds critical Atlassian Data Center flaw CVE-2026-21589 to KEV after exploitation within hours of public PoC

CVE-2026-21589 (CVSS 9.3) is a path-traversal/arbitrary file access flaw affecting eight Atlassian Data Center products, including Confluence, Jira, Bitbucket and Bamboo. watchTowr published technical details Oct 6 and exploitation attempts followed quickly; VulnCheck tracked exploitation from Oct 7. Security Affairs and Senserva report the CISA KEV addition on Oct 15 with a federal deadline of Oct 18, but CISA’s own alert was not reviewed and early reports said it was not yet listed. Atlassian published fixed versions; where patching is delayed, cut instances off from the internet.

Threat Actor & APT Activity

Oct 20Reported CISA/FBI advisory: SafePay ransomware has hit 600+ critical-infrastructure organizations

BleepingComputer, CyberSecurityNews and GBHackers report a joint CISA/FBI advisory saying SafePay actors have compromised at least 600 organizations since 2024, exploiting VPNs and also targeting backup systems to block recovery. The advisory text itself was not found in search, so the date and counts rest on secondary summaries.

BleepingComputer · GBHackers
Oct 19Reuters: one hacker used AI agents to break into 100+ company sites for about $5,000

Reuters reports, citing NorForge researcher Snorre Fagerland, that a Chinese-speaking operator used the open-source Cairn agent platform against more than 1,200 sites from Sept 25, compromising over 100 including Deere, SharkNinja and Cummins, at roughly $50 in tokens per success. Agent worker names suggest Claude Code and DeepSeek models, which is NorForge’s reading and not a confirmed fact. Reuters could not establish how much data was taken; Deere reported remediation and Cummins said it was investigating a third-party vendor site. The Next Web noted it had not independently verified the intrusions.

CP24 (Reuters) · The Next Web
Oct 15Google/Mandiant: China-nexus ARMORY CASTLE exploited BeyondTrust Remote Support zero-day CVE-2026-102764 since Aug 29

Google Threat Intelligence Group and Mandiant attribute exploitation to ARMORY CASTLE (formerly UNC5221, also linked to WARP PANDA). The flaw (CVSS 4.0 9.3) is an improper origin validation bug in an internal messaging component that lets an unauthenticated attacker perform file operations. Mandiant found the SAWFLY web shell, credential harvesting and downstream access. BeyondTrust found the hosted activity Sept 28, shipped patch BT26-05 on Oct 8 and disclosed the CVE Oct 15. All Remote Support versions through 26.2.3 are affected; self-hosted customers should confirm the patch is applied. A search summary says CISA added the flaw to KEV on Oct 16 with an Oct 19 federal deadline (CISA’s alert was not reviewed). Details come from search summaries; sources differ slightly on SaaS patch timing.
