Anthropic

Sep 22Claude optimizes 30+ open-source biomolecular modeling tools, launches $1M protein-design competition with Adaptyv Bio

Working within the "Claude Science" framework and supervised by two Anthropic staff with biology (not inference-optimization) backgrounds, Claude rewrote 36 model implementations across 30+ open-source biomolecular tools — structure prediction, hallucination, structure generation, inverse folding, genomics, and protein language models — for a roughly 4x average speedup, plus a new low-memory mode that runs 10,000+ token biomolecular systems on a single Nvidia GPU node. Anthropic open-sourced the optimized code and, with Adaptyv Bio, launched a protein-design competition: $1M in Claude credits plus $1M in Adaptyv wet-lab validation for 5,000+ designs, with Modal (compute) and Twist Bioscience (DNA synthesis) also contributing.

OpenAI

upcoming Oct 14GPT-5.5 to be retired from ChatGPT, ChatGPT Work and Codex

OpenAI will pull GPT-5.5 from plan-based access in ChatGPT, ChatGPT Work and Codex on October 14 — just 174 days after its April 23 launch — pointing users to GPT-5.6 Sol or GPT-6 Astra instead. API access to GPT-5.5 continues unaffected. Regular ChatGPT users should see a seamless model switch; Codex users on GPT-5.5 need to migrate workflows before the deadline.
